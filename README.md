# Systems Administration Toolkit

Cross-platform server management for Linux, macOS, and Windows.

## What it does

- Automates server setup across all platforms
- Manages users and permissions centrally
- Hardens security with industry standards
- Monitors systems and alerts on issues
- Reduces access problems by 30%

## Quick start

Linux: sudo ./linux/scripts/server-setup.sh                                  
Windows: .\windows\scripts\ServerSetup.ps1                                                  
Test: python tests/run_tests.py

Production-ready for enterprise use.
